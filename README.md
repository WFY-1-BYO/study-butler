# 学习管家 (Study Butler)

一个完全属于自己、不依赖任何平台的离线学习管理 App。

## 特点

- **不联网也能用** — 日程、提醒、资料全部本地存储
- **没有任何付费依赖** — 无订阅、无账号、无后台服务
- **数据在你自己手里** — 可随时导出 JSON 备份
- **三类科目** — 数学 / 化学 / 生物

## 四个页面

| 页面 | 解决什么 |
|---|---|
| 今日 | 打开就看到最多 3 件事 + 崩溃时的保底方案 |
| 日程 | 记死线，系统闹钟提前 30 分钟 + 到点双提醒 |
| 学习计划 | 按科目/周次备料：3 知识点 + 10 题 + 错因 + 易错点 |
| 资料库 | 生成的学习包自动归档，按科目筛选 |

## 安装

下载 Releases 里的 `学习管家.apk`，传到手机安装。

装完**必须**做三步（否则到点不响）：

1. 允许通知
2. 电池 → 后台耗电管理 → 允许后台高耗电
3. 自启动（vivo 特有）

## 技术栈

- 前端：单文件 HTML（无框架、无依赖）
- 壳：Android 原生 WebView（Java，无第三方库）
- 提醒：Android `AlarmManager` 精确闹钟 + `Notification`
- 重启恢复：`BootReceiver`
- 包体：35 KB

## AI 接入（可选）

设置里可填任意 OpenAI 兼容接口：
- DeepSeek：`https://api.deepseek.com/v1`
- 通义：`https://dashscope.aliyuncs.com/compatible-mode/v1`
- 本地 llama.cpp：`http://127.0.0.1:8080/v1`

不填也能用（模板模式）。Key 只存本机。
